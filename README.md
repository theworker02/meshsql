# meshsql

Mesh URLs and sql query parts with stable normalization.

**Site:** https://theworker02.github.io/meshsql/

## Install / run

```bash
git clone https://github.com/theworker02/meshsql.git
cd meshsql
node src/cli.js
node --test
```
